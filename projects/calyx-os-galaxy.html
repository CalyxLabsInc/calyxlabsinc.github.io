Calyx OS Galaxy Version

Calyx OS Galaxy Version is the first open source project from Calyx Labs Inc. It is planned as an Ubuntu-based desktop Linux distribution with an original Galaxy visual identity.

Project vision

Deliver a polished desktop environment that feels coherent from installation through everyday use while remaining familiar to the broader Ubuntu ecosystem.

Planned priorities

  • Approachable installation and onboarding
  • Cohesive purple-forward Galaxy appearance
  • Sensible default applications and settings
  • Developer-friendly tools and documentation
  • Transparent open source development
Status: In development. Features, schedules, and technical decisions may change.

Development

Source code, issue tracking, releases, and contribution guidance are intended to be published through the Calyx Labs GitHub organization.

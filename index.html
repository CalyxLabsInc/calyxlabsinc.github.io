Calyx PGP Client

v0.1.0-alpha • Package: com.calyxlabs.pgpclient

An all-in-one Android OpenPGP cryptographic workspace supporting RFC 4880 & RFC 9580 standards with post-quantum ML-KEM-1024 + ML-DSA-87 key suites and AES-256-GCM + SHA-256 authenticated encryption.

  • ✓ Complete Crypto Workspace: Fast access to Manage Keys, Encrypt/Decrypt Notepad, and Encrypt/Decrypt local `.asc` / `.pgp` files.
  • ✓ Instant QR Key Verification: Audit OpenPGP v4/v6 fingerprints, hardware keyring health, and PBKDF2 + AES-256-GCM status via QR code.
  • ✓ 100% Local Keyring: Zero cloud key uploads—private keys never leave your device hardware.

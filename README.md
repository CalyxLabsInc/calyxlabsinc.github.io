# Calyx Labs Inc. — Official Developer Website (`calyxlabsinc.github.io`)

Official GitHub Pages repository for **Calyx Labs Inc.**, founded and engineered by **Tristen Martinez (aka Calyxia)** in Cleveland, Ohio, USA.

## Signature Brand & Architecture
- **Colorway**: Obsidian Black (`#060609`) & Neon Pink (`#ff007f`)
- **Zero-Data Guarantee**: We collect **no data whatsoever** on users.
- **Canonical Google Play Privacy Policy**: [`/google_play_privacy_policy.txt`](https://calyxlabsinc.github.io/google_play_privacy_policy.txt)
- **Contact**: `calyxlabsinc@gmail.com`

## Pages & Modules Included
- `index.html` — Home Page showcasing flagship Android releases, Linux utilities, signing identity, and zero-data commitment.
- `pgp-client.html` — Dedicated module for **Calyx PGP Client (`v0.1.0-alpha`, `com.calyxlabs.pgpclient`)**, featuring RFC 4880 / 9580 OpenPGP, ML-KEM-1024 + ML-DSA-87 post-quantum suites, interactive screenshot gallery, and SHA-256 certificate verification.
- `zappy-bird.html` — Dedicated module for **Zappy Bird (`v1.0.0` Official Release)**, highlighting Solo Play, WiFi Versus, 10-Tube Power-Ups (E-Bomb, Teleporter, Super Jump), official screenshots, and an interactive playable HTML5 demo.
- `linux-tools.html` — Dedicated module for **Calyx Linux**, **Calyx Terminal**, **Calyx Web Server**, and the **Calyx Security Operations Center (SOC)** inspired by Kodachi Linux SOC.
- `about.html` — Company overview, authorship credit for **Tristen Martinez (aka Calyxia)**, and full APK/OpenPGP signing fingerprints.
- `privacy.html` — Formatted Privacy Policy overview with embedded verbatim preview and download for `google_play_privacy_policy.txt`.
- `google_play_privacy_policy.txt` — Plain-text zero-data privacy policy at the root path `https://calyxlabsinc.github.io/google_play_privacy_policy.txt`.
- `contact.html` — Interactive email composer that formats inquiries and opens the user's email app addressed to `calyxlabsinc@gmail.com`.

## Deploying to GitHub Pages
1. Extract the contents of `calyxlabsinc.github.io.zip`.
2. Upload all extracted files (`index.html`, `google_play_privacy_policy.txt`, `assets/`, etc.) directly to the root of your `calyxlabsinc.github.io` repository.
3. Commit and push to your `main` (or `master`) branch. GitHub Pages will automatically build and serve your site at `https://calyxlabsinc.github.io/`.

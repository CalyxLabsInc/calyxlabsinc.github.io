3. APPLICATION OVERVIEW AND SUPPORTED FORMATS

Calyx Document Editor is a local-first document creation, viewing, formatting, annotation, signing, and editing application developed by Calyx Labs Inc. for Android devices running Android 10 (API Level 29) through Android 17 (API Level 37).

The Application supports opening, editing, formatting, and exporting across twenty-five (25) document file extensions:
.doc, .docx, .docm, .dot, .dotx, .odt, .pdf, .rtf, .txt, .tex, .wpd, .wps, .pages, .epub, .mobi, .azw, .azw3, .djvu, .oxps, .xps, .md, .markdown, .log, .msg, and .eml.

The Application also includes over one hundred (100) built-in document fonts and supports importing custom user font files across eleven (11) font extensions:
.otf, .otc, .ttf, .ttc, .woff2, .woff, .pfm, .afm, .pfb, .eot, and .shx.

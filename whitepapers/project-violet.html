Project Violet Whitepaper

A living document describing current direction. Plans may change as development and validation continue.

Abstract

Project Violet is a placeholder for a future Calyx Labs game. This paper outlines the pre-production questions that should be answered before the project is announced.

1. Creative foundation

The project should define its genre, player fantasy, core interaction loop, visual direction, tone, and intended audience.

2. Production foundation

  • Prototype the core loop before full production.
  • Select platforms and technology based on tested requirements.
  • Include accessibility goals in initial design.
  • Establish content, performance, and quality targets.

3. Distribution

Commercial model, platform availability, online features, licensing, and long-term support remain undecided.

4. Status

Project Violet is not an announced game. The name, scope, and all concepts are placeholders.

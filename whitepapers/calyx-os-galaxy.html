Calyx OS Galaxy Version Whitepaper

A living document describing current direction. Plans may change as development and validation continue.

Abstract

Calyx OS Galaxy Version is planned as an open source, Ubuntu-based desktop Linux distribution developed by Calyx Labs Inc. The project aims to combine a recognizable visual identity with a practical system for everyday computing and development.

1. Goals

  • Provide a coherent, welcoming desktop experience.
  • Build upon a widely supported Linux ecosystem.
  • Offer transparent source code and contribution pathways.
  • Create maintainable branding, tooling, and documentation.

2. Intended audience

The intended audience includes Linux newcomers, desktop users, students, creators, and software developers who value a guided experience without losing access to the underlying platform.

3. Technical direction

The distribution is expected to use Ubuntu as its foundation. Exact base release, desktop environment, packaging approach, update policy, hardware targets, and bundled applications will be documented as decisions are finalized.

4. User experience

The Galaxy identity will guide color, typography, icons, wallpapers, onboarding, and system defaults. Accessibility and legibility should take priority over decoration.

5. Open source governance

Public repositories should include contribution guidance, issue templates, a code of conduct, license information, and reproducible build documentation. Third-party components will retain their respective licenses.

6. Security and privacy

The project should inherit timely upstream security updates, minimize unnecessary services, document telemetry if any exists, and provide clear channels for responsible vulnerability reporting.

7. Roadmap framework

  1. Architecture and visual prototypes
  2. Internal development images
  3. Public pre-release testing
  4. Release candidate and documentation freeze
  5. Stable release and maintenance cycle

8. Limitations

This document describes intent, not a guarantee of features or delivery dates. Plans will evolve through engineering validation and community feedback.

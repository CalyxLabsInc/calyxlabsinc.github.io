OPERATING DISTRIBUTION

Calyx Linux

A custom-built Linux distribution styled in Calyx Labs' signature Obsidian Black & Neon Pink colorway. Engineered for privacy researchers, cryptographic operators, and developers who demand an air-tight desktop environment out of the box.

  • ✓ Built-in Calyx SOC Desktop Widget: Live Conky/GTK operational security monitor inspired by Kodachi Linux SOC.
  • ✓ Hardened Kernel Parameters: Pre-tuned sysctl profiles mitigating speculative execution, pointer leaks, and ptrace snooping.
  • ✓ Native OpenPGP & Post-Quantum Suite: Seamless interoperability with Calyx PGP Client keyrings and `.asc` / `.pgp` containers.
COMMAND-LINE EMULATOR

Calyx Terminal

A fast, memory-safe, zero-telemetry terminal environment designed for security auditing, cryptographic key management, and rapid systems engineering.

  • ✓ Obsidian & Neon Pink High-Contrast Theme: Razor-sharp typography tuned for extended cryptographic and reverse-engineering sessions.
  • ✓ Ephemeral History Mode: Optional zero-disk shell history mode so sensitive CLI passphrases or fingerprints never touch non-volatile storage.
  • ✓ Integrated PGP & SHA-256 Helpers: Quick-verify checksums, X.509 certificates, and OpenPGP ASCII armor directly in the terminal.
FOSS INFRASTRUCTURE UTILITY

Calyx Web Server

Created by Tristen Martinez (aka Calyxia) as a lightweight, stable, and simple alternative to Nginx and Apache. Built in pure Python with zero external dependencies, automatic installation scripting, native systemd boot integration, reverse proxying, HTTPS support, and strict security hardening settings.
